## 🚀 如何使用

### 步骤 1：获取测试地址

1. **访问水龙头**：https://nileex.io/join/getJoinPage
2. **输入你的测试网地址**
3. **领取测试币**：每天可领取 2000 TRX

### 步骤 2：查找活跃地址

访问 Nile 区块浏览器：https://nile.tronscan.org

找一个有交易记录的地址，例如：
- `TJFJTCgJCmq1ghzZEagDTifHNtNgK4rnRL`（示例地址）

### 步骤 3：使用风险评估系统

1. **打开应用**：http://localhost:5173/
2. **进入风险评估页面**
3. **输入地址**：粘贴 Nile 测试网地址
4. **点击"开始分析"**
5. **切换标签查看**：
   - 📜 历史交易
   - 🚫 黑名单检测
   - 💰 资金流动
   - 🔗 地址关联

## 📊 功能说明

### 1. 历史交易（📜）
- 显示最近 20 笔交易
- 包含交易哈希、发送方、接收方、金额、时间
- 区分成功/失败状态

### 2. 黑名单检测（🚫）
- 基于交易模式的风险评估
- 显示风险标签
- 可疑模式识别

### 3. 资金流动（💰）
- 统计总流入/流出
- 交易笔数和关联地址数
- 可疑模式检测：
  - 高频交易
  - 小额洗钱
  - 异常时间模式

### 4. 地址关联（🔗）
- 显示前 10 个关联地址
- 关系类型识别
- 风险等级评估（低/中/高）

## 🔍 数据来源

### TronScan API
- **端点**：https://nileapi.tronscan.org
- **限制**：50 QPS/IP
- **数据**：实时链上数据

### 查询示例

```typescript
// 查询交易历史
const txs = await TronService.getTransactions(address, 20);

// 分析资金流动
const flow = await TronService.analyzeFundFlow(address);

// 分析地址关联
const relations = await TronService.analyzeAddressRelations(address);
```

## ⚠️ 注意事项

### 1. 地址格式
- 必须以 `T` 开头
- 长度为 34 个字符
- 示例：`TJFJTCgJCmq1ghzZEagDTifHNtNgK4rnRL`

### 2. 网络选择
- 当前使用：**Nile 测试网**
- 主网地址不适用
- 需要测试网地址

### 3. 数据延迟
- 实时数据，延迟 < 3秒
- 新交易可能需要等待确认

### 4. API 限制
- QPS：50 请求/秒/IP
- 建议添加缓存机制
- 避免频繁刷新

## 🐛 常见问题

### Q1：显示"未找到该地址的信息"
**原因**：
- 地址格式不正确
- 该地址在 Nile 测试网上没有交易记录

**解决**：
- 检查地址格式
- 使用有交易记录的地址
- 访问 https://nile.tronscan.org 查找活跃地址

### Q2：加载很慢或失败
**原因**：
- 网络问题
- API 限流
- 地址交易记录过多

**解决**：
- 检查网络连接
- 等待几秒后重试
- 使用交易较少的地址测试

### Q3：数据不准确
**原因**：
- 测试网数据可能不完整
- 算法基于启发式规则

**解决**：
- 这是正常现象
- 仅供演示和测试
- 主网数据会更准确
