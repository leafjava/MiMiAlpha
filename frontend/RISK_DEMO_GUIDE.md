# 风险评估系统 Demo 使用指南

## 🎯 Demo 概述

这是一个完整的风险评估系统 Demo，展示了四大核心功能：
1. 📜 链上历史交易查询
2. 🚫 黑名单地址检测
3. 💰 资金流动分析
4. 🔗 地址关联分析

## 🚀 如何使用

### 步骤 1：启动项目

```bash
cd Hackathon/frontend
npm run dev
```

### 步骤 2：访问风险评估页面

1. 打开浏览器访问 `http://localhost:5173/`
2. 点击 Spline 3D 动画进入首页
3. 点击顶部导航栏的 "⚠️ 风险评估" 按钮

或者：

1. 在 FacilitatorXHome 页面
2. 点击 "🔐 x402 支付拦截与治理" 卡片
3. 自动跳转到风险评估页面

### 步骤 3：体验功能

#### 1. 基础评估（📊 标签）

1. 在地址输入框输入任意地址（例如：`0xabcd1234567890abcdef1234567890abcdef1234`）
2. 点击"开始分析"按钮
3. 等待分析完成提示

#### 2. 历史交易（📜 标签）

点击"📜 历史交易"标签，查看：
- 3 条模拟交易记录
- 交易哈希、发送方、接收方
- 交易金额和时间
- 交易状态（成功/失败）

**视觉效果**：
- 成功交易显示绿色 ✅ 标识
- 失败交易显示红色 ❌ 标识
- Hover 时卡片上移并显示阴影

#### 3. 黑名单检测（🚫 标签）

点击"🚫 黑名单检测"标签，查看：
- 地址安全状态（✅ 安全地址）
- 风险标签：[高频交易] [新地址]
- 被举报次数：0
- 最后举报时间：N/A

**视觉效果**：
- 安全地址：绿色 ✅ 图标
- 风险地址：红色 ❌ 图标
- 风险标签：橙色边框标签

#### 4. 资金流动（💰 标签）

点击"💰 资金流动"标签，查看：

**统计数据**：
- 总流入：5,000 USDD
- 总流出：3,500 USDD
- 交易笔数：156
- 关联地址数：42

**可疑模式**：
- 🚨 检测到高频小额转账（可能是洗钱行为）
- 🚨 与已知风险地址有交互
- 🚨 存在异常交易时间模式

**视觉效果**：
- 统计卡片：Grid 布局，橙色数值
- 可疑模式：红色警告框

#### 5. 地址关联（🔗 标签）

点击"🔗 地址关联"标签，查看 3 个关联地址：

**低风险地址**：
- 地址：0xabcd...1234
- 关系类型：频繁交易对手
- 交互次数：25
- 总金额：1,200 USDD
- 风险等级：🟢 低风险

**中风险地址**：
- 地址：0xbcde...2345
- 关系类型：资金中转地址
- 交互次数：8
- 总金额：5,000 USDD
- 风险等级：🟡 中风险

**高风险地址**：
- 地址：0xcdef...3456
- 关系类型：可疑关联地址
- 交互次数：3
- 总金额：10,000 USDD
- 风险等级：🔴 高风险

**视觉效果**：
- 低风险：绿色标识
- 中风险：黄色标识
- 高风险：红色标识

## 📊 Demo 数据说明

### 模拟数据特点

1. **历史交易**：
   - 3 条交易记录
   - 包含成功和失败状态
   - 时间戳为相对当前时间

2. **黑名单检测**：
   - 默认为安全地址
   - 包含 2 个风险标签
   - 无举报记录

3. **资金流动**：
   - 正向资金流（流入 > 流出）
   - 156 笔交易
   - 3 个可疑模式

4. **地址关联**：
   - 3 个关联地址
   - 涵盖低/中/高三种风险等级
   - 不同的关系类型

### 真实数据集成

要集成真实数据，需要：

1. **TRON API 集成**：
```typescript
// 历史交易
const response = await fetch(`https://api.trongrid.io/v1/accounts/${address}/transactions`);

// 账户信息
const response = await fetch(`https://api.trongrid.io/v1/accounts/${address}`);
```

2. **黑名单 API**：
```typescript
const response = await fetch(`/api/risk/blacklist/${address}`);
```

3. **链上分析**：
```typescript
const response = await fetch(`/api/risk/analyze/${address}`);
```

## 🔧 技术实现

### 组件结构
```
RiskAssessment.tsx
├── 状态管理
│   ├── activeTab (当前标签)
│   ├── address (地址输入)
│   └── isLoading (加载状态)
├── 模拟数据
│   ├── mockTransactions (历史交易)
│   ├── mockBlacklist (黑名单)
│   ├── mockFundFlow (资金流动)
│   └── mockRelations (地址关联)
└── UI 渲染
    ├── 标签页导航
    ├── 基础评估表单
    ├── 历史交易列表
    ├── 黑名单检测结果
    ├── 资金流动统计
    └── 地址关联列表
```
