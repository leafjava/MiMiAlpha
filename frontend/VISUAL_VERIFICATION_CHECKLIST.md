## 🐛 常见问题排查

### 问题 1: 新服务不显示
**原因**: 浏览器缓存
**解决**: 
1. 按 Ctrl+Shift+R (Windows) 或 Cmd+Shift+R (Mac) 强制刷新
2. 或清除浏览器缓存后刷新

### 问题 2: AINFT 徽章不显示
**原因**: CSS 未加载
**解决**:
1. 检查浏览器控制台是否有 CSS 错误
2. 确认 CSS 文件已保存
3. 重启开发服务器

### 问题 3: 合约交互失败
**原因**: Hardhat 节点未运行或合约未部署
**解决**:
1. 确认 Hardhat 节点正在运行 (`npm run node`)
2. 确认合约已部署 (`npm run deploy:local`)
3. 检查 OKX 钱包是否连接到正确的网络

### 问题 4: 钱包连接失败
**原因**: 网络配置错误
**解决**:
1. 在 OKX 钱包中添加 Hardhat Local 网络
2. RPC URL: http://127.0.0.1:8545
3. Chain ID: 1337
4. 货币符号: ETH
