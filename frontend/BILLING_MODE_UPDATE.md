# 💳 计费模式分类更新

## 📋 更新概述

根据服务的实际使用特性，将订阅服务分为两种计费模式：
1. **按次计费 (Per Use)** - 实时解析请求内容，计数并扣费
2. **按时计费 (Per Time)** - 租约到期后自动撤销 Session 或 API 访问

---

### 2️⃣ 按时计费 (Per Time)

**适用场景**: VPN、AI 口语练习等需要持续稳定使用的工具

**技术特点**:
- ✅ 租约到期自动撤销
- ✅ Session 或 API 访问管理
- ✅ 适合持续使用场景
- ✅ 稳定的访问权限
- ✅ 无需实时计数

**服务列表**:
1. **Astrill VPN** 🔒
   - 单价: $1.2/天
   - 计费单位: 天
   - 描述: 租约到期后自动撤销 Session，按天计费
   - 特点: 全天候稳定连接

2. **ELSA Speak** 🗣️
   - 单价: $0.8/天
   - 计费单位: 天
   - 描述: AI 口语练习，租约到期后自动撤销访问权限
   - 特点: 持续练习，无限次数

**技术实现**:
```typescript
interface PerTimeSubscription {
  billingMode: 'per-time';
  billingUnit: '天' | '小时';
  // 创建临时 Session
  // 设置过期时间
  // 到期自动撤销访问
}
```

**用户体验**:
- ⏰ 按时间段租赁
- 🔐 自动 Session 管理
- ⏱️ 到期自动撤销
- 🔄 可续租
- 📅 租期可视化
