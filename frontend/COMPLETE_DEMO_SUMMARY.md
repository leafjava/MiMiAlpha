### 2. 四大核心功能

#### 📜 链上历史交易查询
**功能**：
- 显示交易哈希、发送方、接收方
- 显示交易金额和时间戳
- 区分成功/失败状态

**数据**：
- 3 条模拟交易记录
- 包含不同的交易状态
- 真实的时间戳格式

**视觉**：
- 成功：绿色 ✅
- 失败：红色 ❌
- Hover 上移效果

#### 🚫 黑名单地址检测
**功能**：
- 检测地址安全状态
- 显示风险标签
- 显示举报统计

**数据**：
- 安全/风险状态
- 2 个风险标签
- 举报次数和时间

**视觉**：
- 安全：绿色图标
- 风险：红色图标
- 标签：橙色边框

#### 💰 资金流动分析
**功能**：
- 统计流入/流出金额
- 统计交易笔数
- 识别可疑模式

**数据**：
- 4 个统计指标
- 3 个可疑模式
- 详细的警告信息

**视觉**：
- Grid 卡片布局
- 红色警告框
- 橙色数值高亮

#### 🔗 地址关联分析
**功能**：
- 显示关联地址列表
- 标注关系类型
- 评估风险等级

**数据**：
- 3 个关联地址
- 低/中/高风险
- 交互统计数据

**视觉**：
- 🟢 低风险
- 🟡 中风险
- 🔴 高风险

## 🚀 使用方法

### 快速开始
```bash
# 1. 进入项目目录
cd Hackathon/frontend

# 2. 启动开发服务器
npm run dev

# 3. 打开浏览器
http://localhost:5173/

# 4. 导航到风险评估
点击 "⚠️ 风险评估" 或 "🔐 x402 支付拦截与治理"
```

### 体验流程
1. 输入地址并点击分析
2. 切换到"📜 历史交易"查看交易记录
3. 切换到"🚫 黑名单检测"查看安全状态
4. 切换到"💰 资金流动"查看资金分析
5. 切换到"🔗 地址关联"查看关联网络
