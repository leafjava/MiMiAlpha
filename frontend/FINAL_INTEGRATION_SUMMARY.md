## 🚀 如何使用

1. **启动项目**：
```bash
cd Hackathon/frontend

```

2. **访问应用**：
```
http://localhost:5173/
```

3. **进入风险评估**：
   - 点击顶部导航 "⚠️ 风险评估"
   - 或点击首页 "🔐 x402 支付拦截与治理" 卡片

4. **输入测试地址**：
```
TJFJTCgJCmq1ghzZEagDTifHNtNgK4rnRL
```

5. **点击"开始分析"**

6. **切换标签查看**：
   - 📜 历史交易
   - 🚫 黑名单检测
   - 💰 资金流动
   - 🔗 地址关联

## 🔍 数据来源

### TronScan API（主要）
- **端点**：https://nileapi.tronscan.org
- **优势**：数据更详细，包含确认状态、费用等
- **限制**：50 QPS/IP
- **延迟**：< 3秒

### TronGrid API（备用）
- **端点**：https://nile.trongrid.io
- **优势**：官方 API，稳定性高
- **限制**：50 QPS/IP（无 API key）

## ⚠️ 注意事项

### 1. 地址格式
- ✅ 正确：`TJFJTCgJCmq1ghzZEagDTifHNtNgK4rnRL`
- ❌ 错误：`0x...`（以太坊地址）
- ❌ 错误：短地址或格式不对

### 2. 网络选择
- ✅ 当前：Nile 测试网
- ❌ 主网地址不适用
- 💡 主网地址以 T 开头但数据在不同网络

### 3. API 限制
- QPS：50 请求/秒/IP
- 建议：不要频繁刷新
- 优化：已添加加载状态，避免重复请求

### 4. 数据准确性
- 测试网数据可能不完整
- 算法基于启发式规则
- 仅供演示和测试

## 🐛 故障排除

### 问题 1：显示"未找到该地址的信息"
**解决方案**：
1. 检查地址格式（T 开头，34 位）
2. 确认是 Nile 测试网地址
3. 访问 https://nile.tronscan.org 验证地址
4. 使用有交易记录的地址

### 问题 2：加载很慢
**解决方案**：
1. 检查网络连接
2. 等待 5-10 秒
3. 刷新页面重试
4. 检查浏览器控制台错误

### 问题 3：CORS 错误
**解决方案**：
1. TronScan API 支持跨域，不应该有问题
2. 如果有问题，检查浏览器设置
3. 或使用代理服务器

### 问题 4：数据为空
**解决方案**：
1. 该地址可能真的没有交易
2. 尝试其他活跃地址
3. 访问区块浏览器确认
