# AI 综合风险评估功能使用指南

## 功能概述

智能风险评估系统现已集成本地 Ollama AI 模型，可以基于链上数据进行综合分析和风险评估。

## 工作流程

```
1. 输入 TRON 地址 → 基础验证
2. 查询历史交易 → 获取交易记录
3. 黑名单检测 → 识别风险标签
4. 资金流动分析 → 计算流入流出
5. 地址关联分析 → 映射关系网络
6. AI 综合评估 → 生成智能报告
```

## 支持的模型

### ✅ 推荐模型

**qwen3:4b-instruct-2507-q4_K_M**
- 大小：2.5 GB
- 特点：指令微调，支持 JSON 输出
- 速度：快（4B 参数）
- 准确度：高
- **最适合风险评估任务**

### ⚠️ 可选模型

**deepseek-coder:6.7b**
- 大小：3.8 GB
- 特点：代码专用模型
- 速度：中等（6.7B 参数）
- 准确度：高（但偏向代码分析）
- 适合：技术分析场景

### ❌ 不推荐

**qwen3-embedding:0.6b-q8_0**
- 这是嵌入模型，不支持文本生成
- 无法用于风险评估

## 使用步骤

### 1. 启动 Ollama

```bash
# Windows
ollama serve

# 或者 Ollama 已作为服务运行
```

### 2. 验证模型

```bash
ollama list
```

应该看到：
```
NAME                             ID              SIZE      MODIFIED
qwen3:4b-instruct-2507-q4_K_M    0edcdef34593    2.5 GB    2 weeks ago
deepseek-coder:6.7b              ce298d984115    3.8 GB    4 weeks ago
```

### 3. 配置前端

在"基础评估"页面：
- **API 地址**：`http://localhost:11434`（默认）
- **模型选择**：`qwen3:4b-instruct-2507-q4_K_M`（推荐）

### 4. 执行分析

1. 输入 TRON Nile 测试网地址（例如：`TJFJTCgJCmq1ghzZEagDTifHNtNgK4rnRL`）
2. 点击"开始分析"
3. 依次查看各个标签页的数据
4. 最后点击"🤖 AI 综合评估"标签

### 5. 查看结果

AI 会生成包含以下内容的报告：

#### 综合评分（0-100）
- 0-30：⛔ 极高风险（critical）
- 31-50：🔴 高风险（high）
- 51-70：🟡 中等风险（medium）
- 71-100：🟢 低风险（low）

#### 详细分析
- **地址验证分析**：格式、创建时间、活跃度
- **交易模式分析**：频率、金额、时间分布
- **资金流动分析**：流入流出比例、异常模式
- **关联关系分析**：关联地址风险、交互模式

#### 安全建议
- 3-5 条针对性建议
- 基于实际链上数据
- 可操作的安全措施

## 评估维度

### 1. 地址格式验证
- ✅ TRON 地址格式（T 开头，34 位）
- ⚠️ 新创建地址（可能是临时地址）
- ❌ 格式异常

### 2. 交易行为模式
- 交易频率（高频 vs 低频）
- 交易金额（大额 vs 小额）
- 交易时间（正常 vs 异常时段）
- 交易对手（多样 vs 集中）

### 3. 资金流动特征
- 流入流出比例
- 资金停留时间
- 中转特征识别
- 洗钱模式检测

### 4. 地址关联网络
- 关联地址数量
- 关联地址风险等级
- 交互频率和金额
- 关系类型识别

## 常见问题

### Q1: AI 评估失败，提示 404 错误

**原因**：模型名称不正确或模型未安装

**解决**：
```bash
# 查看可用模型
ollama list

# 确保使用正确的模型名称
qwen3:4b-instruct-2507-q4_K_M
```

### Q2: 无法连接到 Ollama

**原因**：Ollama 服务未启动

**解决**：
```bash
# 启动 Ollama
ollama serve

# 或检查服务状态
curl http://localhost:11434/api/tags
```

### Q3: AI 返回格式错误

**原因**：模型不支持 JSON 格式输出

**解决**：
- 使用推荐的 `qwen3:4b-instruct` 模型
- 该模型经过指令微调，支持结构化输出

### Q4: 分析速度慢

**原因**：模型较大或硬件性能限制

**优化**：
- 使用 4B 参数的 qwen3 模型（推荐）
- 避免使用 6.7B 的 deepseek-coder
- 确保有足够的 RAM（至少 8GB）

### Q5: 评估结果不准确

**原因**：链上数据不足或地址无交易记录

**说明**：
- AI 基于实际链上数据分析
- 新地址或无交易地址数据有限
- 建议使用有交易历史的地址测试
