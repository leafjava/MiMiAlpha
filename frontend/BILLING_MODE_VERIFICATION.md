## 🐛 常见问题

### 问题 1: 新服务不显示
**症状**: 只看到 5 个服务，没有 Astrill VPN 和 ELSA Speak

**解决方案**:
1. 强制刷新浏览器 (Ctrl+Shift+R)
2. 清除浏览器缓存
3. 检查浏览器控制台是否有错误

### 问题 2: 计费模式筛选器不显示
**症状**: 没有看到 "💳 计费模式" 部分

**解决方案**:
1. 检查 CSS 文件是否正确加载
2. 查看浏览器控制台的 CSS 错误
3. 确认 SubscriptionMarket.css 已更新

### 问题 3: 筛选功能不工作
**症状**: 点击筛选按钮没有反应

**解决方案**:
1. 检查浏览器控制台的 JavaScript 错误
2. 确认 React 组件已正确更新
3. 重启开发服务器

### 问题 4: 样式显示不正确
**症状**: 徽章颜色错误或布局混乱

**解决方案**:
1. 清除浏览器缓存
2. 检查 CSS 文件是否有冲突
3. 确认所有 CSS 类名正确
