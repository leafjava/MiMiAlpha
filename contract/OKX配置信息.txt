【配置步骤】
1. 确保 Hardhat 节点正在运行
   命令: npm run node

2. 在 OKX 钱包中添加网络
   - 点击网络选择器
   - 点击"添加网络"
   - 填入上面的网络配置

3. 导入测试账户
   - 点击"导入账户"
   - 选择"私钥导入"
   - 粘贴上面的私钥

4. 添加 cUSD 代币
   - 点击"添加代币"
   - 选择"自定义代币"
   - 填入代币信息

5. 验证
   - 切换到 Hardhat Local 网络
   - 应该看到 10,000 ETH
   - 应该看到 1,000,000 cUSD

========================================

【快速命令】
启动节点: npm run node
部署合约: npx hardhat run scripts/deploy-all.js --network localhost
交互测试: npx hardhat run scripts/interact.js --network localhost
打开控制台: npx hardhat console --network localhost
