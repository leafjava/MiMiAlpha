## 💡 核心命令速查

```bash
# 安装和编译
npm install              # 安装依赖
npm run compile          # 编译合约
npm run clean            # 清理缓存

# 测试
npm test                 # 运行测试
npm run coverage         # 测试覆盖率

# 部署
npm run node             # 启动本地节点
npm run deploy:local     # 部署到本地节点
npm run deploy:hardhat   # 部署到内存网络

# 交互
npx hardhat console --network localhost  # 启动 Console

# 一键启动
QUICK_START.bat          # Windows 一键启动
```
