## ⚡ 三种启动方式

### 方式 1：一键启动（最简单）✨

**适合：** 新手、快速测试

```bash
# 1. 进入合约目录
cd Hackathon/contract

# 2. 双击运行
QUICK_START.bat

# 3. 选择部署方式
#    选项 1: 启动本地节点（推荐）
#    选项 2: 快速测试
#    选项 3: 部署到 TRON 测试网
```

**脚本会自动：**
- ✅ 检查 Node.js 安装
- ✅ 安装依赖
- ✅ 配置环境变量
- ✅ 编译合约
- ✅ 提供部署选项

---

### 方式 2：命令行启动（推荐）🎯

**适合：** 开发者、日常开发

```bash
# 1. 进入合约目录
cd Hackathon/contract

# 2. 安装依赖（首次运行）
npm install

# 3. 编译合约
npm run compile

# 4. 启动本地节点（终端 1）
npm run node

# 5. 部署合约（终端 2）
npm run deploy:local
```

**或者使用新的部署脚本：**
```bash
npx hardhat run scripts/deploy-all.js --network localhost
```

### 方式 3：快速测试（最快）⚡

## 📋 详细步骤说明

### Step 1: 环境准备

#### 1.1 检查 Node.js

```bash
node --version
# 应该显示 v16.0.0 或更高版本
```

**如果未安装：**
- 下载地址：https://nodejs.org/
- 推荐安装 LTS 版本

#### 1.2 进入项目目录

```bash
cd Hackathon/contract
```

#### 1.3 安装依赖

```bash
npm install
```

**安装的主要依赖：**
- `hardhat`: 以太坊开发环境
- `@openzeppelin/contracts`: 安全的合约库
- `ethers`: 以太坊交互库
- `dotenv`: 环境变量管理

---

### Step 2: 配置环境变量（可选）

```bash
# 复制示例文件
copy .env.example .env
```

**编辑 .env 文件：**
```bash
# 本地测试不需要配置
# 部署到测试网/主网时需要填写

PRIVATE_KEY=你的私钥（不要带0x前缀）
GOERLI_RPC_URL=https://goerli.infura.io/v3/YOUR-PROJECT-ID
ETHERSCAN_API_KEY=你的Etherscan API密钥
```

**⚠️ 安全提示：**
- 不要提交 `.env` 文件到 Git
- 不要在公开场合分享私钥
- 测试网和主网使用不同的私钥

---

### Step 3: 编译合约

```bash
npm run compile
```

**编译成功后会生成：**
```

│   ├── Escrow.sol/
│   │   └── Escrow.json
│   └── MockERC20.sol/
│       └── MockERC20.json

└── solidity-files-cache.json
```

**如果编译失败：**
```bash
# 清理缓存
npm run clean

# 重新编译
npm run compile
```

```javascript
// 1. 加载部署地址
const addresses = require("./contract-addresses.json");

// 2. 连接到 MockERC20
const MockERC20 = await ethers.getContractFactory("MockERC20");
const token = await MockERC20.attach(addresses.contracts.MockERC20);

// 3. 查询余额
const [owner] = await ethers.getSigners();
const balance = await token.balanceOf(owner.address);
console.log("余额:", ethers.formatEther(balance), "MTK");

// 4. 转账测试
const [owner, addr1] = await ethers.getSigners();
const tx = await token.transfer(addr1.address, ethers.parseEther("100"));
await tx.wait();
console.log("转账成功!");

// 5. 查询新余额
const newBalance = await token.balanceOf(addr1.address);
console.log("Addr1 余额:", ethers.formatEther(newBalance), "MTK");
```

## 🌐 部署到 TRON 测试网

### Step 1: 安装 TronBox

```bash
npm install -g tronbox
```

### Step 2: 获取测试币

访问 TRON Nile 测试网水龙头：
- https://nileex.io/join/getJoinPage

### Step 3: 配置私钥

编辑 `.env` 文件：
```bash
PRIVATE_KEY=你的TRON私钥（不要带0x前缀）
```

### Step 4: 创建 TronBox 配置

创建 `tronbox.js`：
```javascript
module.exports = {
  networks: {
    nile: {
      privateKey: process.env.PRIVATE_KEY,
      userFeePercentage: 100,
      feeLimit: 1000 * 1e6,
      fullHost: 'https://nile.trongrid.io',
      network_id: '3'
    }
  },
  solc: {
    version: '0.8.24'
  }
};
```

### Step 5: 部署

```bash
# 编译
tronbox compile

# 部署到 Nile 测试网
tronbox migrate --network nile
```

### Step 6: 验证

访问 TRON Nile 浏览器：
- https://nile.tronscan.org/#/contract/你的合约地址

## 🐛 常见问题解决

### 问题 1: npm install 失败

**错误：** `npm ERR! code ENOENT`

**解决：**
```bash
# 确保在正确的目录
cd Hackathon/contract

# 删除 node_modules 和 package-lock.json
rm -rf node_modules package-lock.json

# 重新安装
npm install
```

### 问题 2: 编译失败

**错误：** `Error: Cannot find module 'hardhat'`

**解决：**
```bash
npm install
npm run compile
```

### 问题 3: 部署失败 - 连接错误

**错误：** `Error: could not detect network`

**解决：**
```bash
# 确保本地节点正在运行
npm run node

# 在新终端部署
npm run deploy:local
```

### 问题 4: 测试失败

**错误：** `Error: Timeout of 40000ms exceeded`

**解决：**
```bash
# 增加超时时间
# 编辑 hardhat.config.cjs
mocha: {
  timeout: 60000  # 增加到 60 秒
}
```

### 问题 5: 找不到合约地址

**错误：** `Cannot find module './contract-addresses.json'`

**解决：**
```bash
# 确保已经部署
npm run deploy:local

# 检查文件是否存在
ls contract-addresses.json
```
